# .github

This repo holds the org-wide defaults for HotLoop-io: issue templates, PR template, code of conduct, security policy, and contributing guide. Any repo in this org that doesn't have its own copy of these files inherits them from here automatically.

It's also home to the actual [org homepage](./profile/README.md), which GitHub renders at [github.com/HotLoop-io](https://github.com/HotLoop-io), and to [HotLoop's org-wide Discussions](https://github.com/orgs/HotLoop-io/discussions), the place for personal and home use questions, ideas, and general chatter about the project.
