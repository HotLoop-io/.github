# .github

Org-wide defaults for HotLoop-io: issue/PR templates, code of conduct, security policy, and contributing guide. Any repo in this org without its own copy of these files inherits them from here.

This is also home to [HotLoop's org-wide Discussions](https://github.com/orgs/HotLoop-io/discussions) — the place for personal/home-use questions, ideas, and general chatter about the project.
