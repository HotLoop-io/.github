# .github

This repo holds the org-wide defaults for HotLoop-io: issue templates, PR template, code of conduct, security policy, and contributing guide. Any repo in this org that doesn't have its own copy of these files inherits them from here automatically.

It's also home to the actual [org homepage](./profile/README.md), which GitHub renders at [github.com/HotLoop-io](https://github.com/HotLoop-io).

One thing worth knowing: [org wide Discussions](https://github.com/orgs/HotLoop-io/discussions) is a GitHub feature enabled here, but the friendly landing page for it lives in a separate repo called [`Discussions`](https://github.com/HotLoop-io/Discussions), not in this one. That split is intentional, not a mistake.

See [github.com/HotLoop-io](https://github.com/HotLoop-io) for the full picture of what's in this org.
