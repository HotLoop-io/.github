# Security Policy

## Reporting a Vulnerability

If you find a security issue in HotLoop or its website/docs infrastructure, please report it privately rather than opening a public issue.

Email **support@hotloop.io** with:

- A description of the issue and its potential impact
- Steps to reproduce (or a proof of concept)
- Any relevant logs, versions, or configuration

We'll acknowledge your report as soon as we can and keep you updated as we investigate and fix it. Please give us a reasonable amount of time to address the issue before any public disclosure.

## Scope

This policy covers HotLoop's own repositories under the HotLoop-io org. Business/Enterprise deployments run through Embernet should also be reported to Embernet directly, in addition to us.
